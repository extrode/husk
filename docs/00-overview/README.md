# Husk

Svelte for .NET projects, without Node.

![How Husk builds](../assets/how-husk-builds.svg)

You write `.svelte` components in your ASP.NET Core project. `dotnet build` compiles them. `dotnet watch` reloads the page when you save one. `dotnet publish` ships plain JavaScript and CSS. Nothing else gets installed: no Node, no npm, no bundler.
