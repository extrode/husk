# 006 linux-musl (Alpine) is unsupported

Date: 2026-10-17. Status: accepted (the user asked for it to be found out; the facts decided it).

## Context

Linux programs build on a C library. Most distributions (Ubuntu, Debian, Fedora) use glibc;
Alpine uses musl, and binaries for one do not run on the other. ClearScript's V8 native packages
exist for glibc Linux only (`linux-musl-*`: 404 on nuget.org, [architecture 001](../architecture/001-compiler-engine.md)).
The alternative was a Jint fallback at 13-25x the build time.

## Where the builds run (checked 2026-10-17)

- riwalqalb.com: GitHub-hosted `ubuntu-latest` (glibc).
- saaaat.com: self-hosted `[self-hosted, saaaat-linux]`, from `scripts/ci-runner/compose.yaml`:
  image `ghcr.io/actions/actions-runner:latest`, whose Dockerfile (actions/runner `images/Dockerfile`)
  is `FROM mcr.microsoft.com/dotnet/runtime-deps:8.0-noble`: Ubuntu 24.04, glibc.

No build of either app runs on Alpine.

## Decision

Husk does not build on linux-musl. On a musl host the build fails with a clear error naming the
cause and the supported platforms. No Jint fallback.

## Consequences

- One engine to test and maintain.
- Only the build machine is affected; Husk's output is static files and runs anywhere.
- Revisit if ClearScript publishes musl packages or a user needs Alpine builds.
